# Calibration assets

The private research workflow uses anonymized human responses collected through Prolific as calibration anchors. Those participant responses are **not included** in this repository.

`example_anchors.csv` contains synthetic demonstration examples that match the input schema expected by the calibration loader. They exist only so the public pipeline is inspectable and runnable.

The examples should be used to learn **reasoning organization**, not writing style, demographic cues, biography, grammar, or vocabulary.

The stage definitions are operational prompt specifications informed by constructive-developmental theory. They are not an official scoring manual and should not be used as psychological diagnoses.
